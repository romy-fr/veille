Jours

Notifications sur l'iPhone (à faire une fois)
  1. Installe l'app gratuite ntfy (App Store) et abonne-toi au sujet ci-dessous (bouton « + »).
  2. Sur GitHub : dépôt → Settings → Secrets and variables → Actions → New repository secret, nom NTFY_TOPIC, valeur = ce même sujet.
  3. Après chaque changement de séances : copie la configuration ci-dessous et colle-la dans la variable SEANCES (même page GitHub, onglet Variables → New repository variable la première fois, puis le crayon pour la modifier). Elle reste privée : tes horaires et lieux ne sont pas publiés dans le dépôt.

GitHub vérifie les séances toutes les heures et envoie le résumé la veille, à l'heure choisie (avec quelques minutes de retard possibles). Les séances restent aussi enregistrées dans ce navigateur.

Trajet

Cartes reconstruites à partir des données ouvertes : NOAA (GFS et AIGFS, domaine public) · ECMWF (IFS et AIFS, CC BY 4.0) · fonds de carte Natural Earth. En haut les modèles physiques, en bas leurs versions IA. Grêle : indice de risque estimé, pas une prévision.
